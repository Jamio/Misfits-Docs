# Operation images

Upload operation screenshots here at 1920x1080 (16:9), preferably as JPG or
WebP. Then edit `data/operation-images.json` and map the operation ID to the
image path:

```json
"2023-08-19-vietnam-pmc-13": "assets/operations/vietnam-pmc-13.jpg"
```

An operation without a mapped image automatically uses `placeholder.svg`.
